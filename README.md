# 🌹 Rose Day

A special Flutter app built to celebrate **Rose Day** (February 7th) — the first day of Valentine's Week. Share love, warmth, and beautiful roses with someone special through a delightful animated experience.

## ✨ Features

- 🌹 **Beautiful Rose Animations** — Lottie-powered animations with rose imagery
- 🎵 **Romantic Background Music** — Plays a romantic audio track to set the mood
- 🎬 **Video Playback** — Embedded video for a heartfelt visual experience
- ✍️ **Animated Text** — Smooth animated text messages using `animated_text_kit`
- 🎨 **Elegant UI** — Styled with Google Fonts for a polished, romantic look
- 📱 **Cross-Platform** — Runs on Android, iOS, Web, Windows, macOS, and Linux

## 🛠️ Tech Stack

- **Flutter** (Dart)
- [`audioplayers`](https://pub.dev/packages/audioplayers) — background music
- [`video_player`](https://pub.dev/packages/video_player) — video playback
- [`lottie`](https://pub.dev/packages/lottie) — smooth animations
- [`animated_text_kit`](https://pub.dev/packages/animated_text_kit) — text animations
- [`google_fonts`](https://pub.dev/packages/google_fonts) — beautiful typography
- [`provider`](https://pub.dev/packages/provider) — state management

## 🚀 Getting Started

1. **Clone the repository**
```bash
   git clone https://github.com/010Ankushsharma/roseday.git
   cd roseday
```

2. **Install dependencies**
```bash
   flutter pub get
```

3. **Run the app**
```bash
   flutter run
```
